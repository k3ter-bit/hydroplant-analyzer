# 🌀 HydroPlant Systems Analyzer

A personal Python project developed from real-world experience at **Kamburu Hydroelectric Power Plant**, Kenya.

## 🔧 Project Description
This tool simulates and analyzes the behavior of a hydropower turbine system. It is based on real operational parameters such as:
- **Maximum turbine speed**: 273 RPM
- **Turbine power output**: Up to 31.4 MW
- **Governor and PLC control**: Opening/closing of guide vanes using servomotors

The project was inspired by Emmanuel's final-year industrial attachment, where he worked on systems involving turbine monitoring, Siemens PLCs, and governor control systems.

## 💻 Tech Stack
- Python
- Pandas
- Matplotlib
- Control systems theory

## 🌍 Use Case
Designed to help students and engineers simulate power output, turbine behavior, and guide vane control, and to provide insight into how automation and data analysis can support preventive maintenance in hydroelectric plants.
